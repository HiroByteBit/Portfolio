# Hiroyuki B. Toyosaki — Premium Editorial Portfolio

A dark, refined, and professional portfolio designed for elite UI/UX and Front-End showcases. This project is built using a "Design First" philosophy, where the portfolio itself serves as a case study in modern web aesthetics and technical precision.

## 🚀 Tech Stack

- **Framework:** [Astro](https://astro.build/) (v6+) — Optimized for high-performance static builds.
- **Styling:** [Tailwind CSS](https://tailwindcss.com/) & Vanilla CSS — Leveraging a custom "Premium Editorial" design system.
- **Iconography:** [Astro Icon](https://github.com/natemoo-re/astro-icon) with Lucide & Simple Icons — No emojis, pure professional SVGs.
- **Interactivity:** Custom JavaScript with `IntersectionObserver` for staggered scroll reveals and an elite custom cursor.
- **Architecture:** Modular component-based structure in `src/pages` and centralized assets in `public/`.

## ✨ Key Features

- **Selected Works Bento Grid:** A high-impact 4-column asymmetric grid showcasing project interfaces.
- **Editorial Typography:** Sophisticated display headings using *Cormorant Garamond* and clear UI text via *DM Sans*.
- **Premium Interactivity:**
    - Custom smooth-following cursor with hover states.
    - Staggered scroll reveals and fade-up animations.
    - CSS-powered noise textures and radial mesh backgrounds.
- **Dynamic Stats:** Project counts and experience metrics calculated directly from data.
- **GitHub Pages Ready:** Configured for seamless deployment.

## 🛠️ Getting Started

### Prerequisites
- Node.js (v22+)
- NPM

### Installation
1. Clone the repository.
2. Install dependencies:
   ```bash
   npm install
   ```

### Development
Start the local development server:
   ```bash
   npm run dev
   ```

### Build
Generate a production-ready build:
   ```bash
   npm run build
   ```

## 📂 Project Structure
- `src/pages/`: Main page content (Astro).
- `src/styles/`: Centralized global CSS and design tokens.
- `src/scripts/`: Custom interactive logic.
- `public/`: Optimized assets and project images.
- `legacy/`: Backup of the original HTML/JS portfolio.
